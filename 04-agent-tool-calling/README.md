# Chat-TRAE File Operations Tool

## 概述
`chat-trae.tool-fileops.py` 是一个基于 LLM 的文件操作工具，提供安全的沙盒化文件操作环境。该工具支持 10 种文件操作功能，通过智能路径验证确保系统安全。

## 核心功能

### 10 种文件操作工具
1. **getCwd** - 获取当前工作目录
2. **listDir** - 列出目录下所有文件和子目录
3. **getFileType** - 获取指定文件的文件类型
4. **readFile** - 读取纯文本文件内容
5. **createFile** - 创建新文件
6. **editFile** - 编辑文件内容（覆盖写入）
7. **mkdir** - 创建新目录
8. **rmdir** - 删除目录（含全部内容）
9. **deleteFile** - 删除指定文件
10. **rename** - 重命名文件或目录

## 安全机制

### safe_path 路径验证
- **沙盒限制**: 所有文件操作仅允许在脚本所在目录内进行
- **路径安全**: 防止目录遍历攻击和越界访问
- **绝对路径解析**: 将相对路径转换为绝对路径进行验证

### 文件类型保护
- **白名单机制**: 仅支持纯文本文件格式
- **编码检测**: 自动检测 UTF-8/GBK 编码
- **类型映射**: 提供人性化的文件类型描述

## 配置说明

### config.ini 配置文件
```ini
[llm]
api_key = your_api_key
base_url = https://open.bigmodel.cn/api/paas/v4/
model = glm-4-flash
```

### 配置参数
- **api_key**: 智谱 AI 的 API 密钥
- **base_url**: API 接口地址（智谱 AI）
- **model**: 使用的模型（glm-4-flash）

## 使用方法

### 运行工具
```bash
python chat-trae.tool-fileops.py
```

### 交互式对话
启动后进入交互式对话模式，可以用自然语言描述文件操作：

```
你: 创建一个 test.txt 文件
[调用工具 createFile] 结果: 已创建文件 test.txt
你: 在 test.txt 中写入一些内容
[调用工具 editFile] 结果: 已更新文件 test.txt
你: 读取 test.txt 的内容
[调用工具 readFile] 结果: 这是一些测试内容...
AI: 文件内容已读取完毕。
```

## 安全特性

### 路径安全
- 所有文件操作都经过 `safe_path()` 验证
- 禁止访问脚本目录外的任何文件
- 自动防止路径遍历攻击

### 文件操作安全
- 仅允许操作支持的文本文件格式
- 自动检测文件编码，避免乱码
- 提供详细的错误提示信息

### 操作限制
- 禁止删除脚本所在目录
- 禁止重命名已存在的文件/目录
- 文件创建前检查是否已存在

## 支持的文件格式
- **文档类**: `.txt`, `.md`, `.mmd`
- **代码类**: `.py`, `.json`, `.ini`, `.cfg`, `.csv`
- **Web类**: `.html`, `.css`, `.js`, `.xml`
- **配置类**: `.yml`, `.yaml`, `.log`, `.bat`

## 工作流程

1. **用户输入**: 接收自然语言命令
2. **LLM 处理**: 通过智谱 AI API 转换为工具调用
3. **路径验证**: `safe_path()` 确保操作安全
4. **工具执行**: 执行对应的文件操作函数
5. **结果返回**: 将操作结果返回给 LLM
6. **多轮对话**: 支持需要多个步骤的复杂操作

## 错误处理

### 常见错误类型
- **路径越界**: 尝试访问脚本目录外的文件
- **文件不存在**: 操作的文件或目录不存在
- **类型不支持**: 尝试操作不支持的文件格式
- **编码错误**: 文件编码无法识别
- **权限问题**: 文件操作权限不足

### 错误提示
所有错误都会提供清晰的中文提示，帮助用户理解问题所在。

## 技术架构

### 核心组件
- **LLM 集成**: 使用智谱 AI 的 glm-4-flash 模型
- **工具实现**: 10 个文件操作函数
- **安全层**: 路径验证和文件类型检查
- **配置管理**: 基于 config.ini 的配置系统

### 数据流
用户输入 → LLM 分析 → 工具调用 → 路径验证 → 操作执行 → 结果返回 → LLM 回应

## 注意事项

1. **API 密钥安全**: 请妥善保管 config.ini 中的 API 密钥
2. **目录权限**: 确保脚本对目标目录有读写权限
3. **文件备份**: 重要文件建议提前备份
4. **测试环境**: 建议在测试环境中验证复杂操作
